# تطبيق تقارير المندوبين

## التشغيل محليًا

```bash
pip install -r requirements.txt
streamlit run app.py
```

## النشر على Streamlit Community Cloud

1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع الملفات الموجودة في هذا المجلد إلى المستودع.
3. افتح Streamlit Community Cloud وسجّل الدخول بحساب GitHub.
4. اختر **Create app** أو **Deploy an app**.
5. اختر المستودع والفرع.
6. اكتب اسم ملف التشغيل: `app.py`
7. اضغط Deploy.
8. بعد اكتمال النشر، انسخ رابط التطبيق وأرسله للمندوبين.

## ملاحظة مهمة عن البيانات

الملفات التي يرفعها المستخدم من داخل التطبيق تكون مرتبطة بجلسة التشغيل، وليست قاعدة بيانات دائمة.
لذلك يجب رفع ملفات البيانات عند بدء جلسة جديدة أو ربط التطبيق لاحقًا بتخزين دائم مثل Google Drive أو Google Cloud Storage.
